> 架构蓝图见 `autonomous-org.md`(后端怎么跑)。**本文是 UI 北极星(人怎么看、怎么管)。** 两者并列。

## 0. 北极星 + 五条设计原则

**一句话**:
> **整个产品就一个视图——一座会呼吸的像素公司。你能从"看整个公司是否健康"一路平滑缩放到"看某一行代码改动",中间不换页;每个像素都连着真实数据、每个手势都是一次真操作;平时它安静待在你余光里,只有真需要你拍板时才把你叫到中心。**

这把三条护城河兑现成交互:**组织即数据**(每个像素=一行数据库)· **像素办公室即 CEO 控制台**(每个手势=一次真操作)· **能在订阅里活**(预算是看得见的能量)。

**五条原则(每个设计决策都拿这五条量)**:
1. **办公室即仪表盘,不是皮肤。** 不做 cozy/严肃两个模式切换;小人就是入口,点它下钻到真实轨迹。
2. **一个连续缩放,不是一堆页面。** 公司→房间→员工→决策→diff 是同一个手势缩进去。
3. **光与姿态讲状态,2 秒看懂。** 文字是兜底、不是主信道。
4. **安静默认、例外才吵。** 成功指标 = 多久才需要你一次。
5. **AI 出主意,Rust 执行后果;危险操作不交给 AI。** 信任是规划旋钮,不是破坏半径旋钮——而且这条要在 UI 上一眼看懂。

## 1. 信息架构:一个连续缩放视图(整个产品的脊梁)

不是"仪表盘+任务板+详情页+diff 页"四个界面拼起来,而是**一条缩放轴上的五个高度**。相机、细节层级(LOD)、手势、键盘都按高度切换行为。

| 高度 | 视口里是什么 | 对应后端 | 2 秒读到 |
|---|---|---|---|
| **L0 公司** | 整层办公室、所有房间、预算能量 | 组织树根 | 公司健康吗?在烧钱吗?卡住了吗? |
| **L1 房间/团队** | 一个房间 + 它的人和家具 | 一个经理子树 / 一类节点 | 这个团队顺不顺、堵没堵? |
| **L2 员工** | 一个小人、桌子、状态光、头顶气泡 | 一个 `agent_node` | 这个人在干嘛、正常吗? |
| **L3 心智/决策** | 这个人的"桌面"——当前任务卡、经理的记忆书翻开 | `decision_log` + 注入的事实 + task | 它为什么这么决定、在啃什么? |
| **L4 diff/裁定** | 真实 git diff 或待你拍板的决策,以"桌上的一张纸"出现 | `saga_step` payload / 分支 diff / 审计裁定 | 接受/驳回/重做——真东西 |

**关键**:L3/L4 **不是盖住办公室的弹窗**,是相机**推近到那张桌子上**——diff 是摊在桌上的一张纸,你始终没丢空间感;`Esc` 或滚轮往外=沿原路推回。这就是"公司→某个决策"像一个动作而不是五个页面的原因。

**工程落地(可行性)**:不追求无限模拟缩放(webview 跨四个数量级保 60fps 很难)。做 **4 档语义层 + 档间 200ms 缓动**,人感觉是"连续"的;每个组件声明 `[minZoom,maxZoom]` 可见区间,公司高度不渲染 diff 文字。原型已经全靠一个 `--s` 缩放变量 + `iso()` 投影驱动,这是自然延伸。

## 2. 控制台核心:像素办公室即仪表盘

### 2.1 小人就是入口(不做模式切换)

| 方案 | 裁决 |
|---|---|
| cozy⇄严肃 开关 | ✗ 把办公室降级成皮肤 |
| HUD 浮层盖在办公室上 | ◐ 只用于"瞥一眼"的环境信号(预算条、头顶问号) |
| 第二个模式/独立 app | ✗ 两套心智模型,非工程师永远找不到审计 |
| **办公室就是仪表盘,小人是入口** | ✓ **采纳** |

**点一个员工 → 它的因果树子树 + 花费**从右侧抽屉滑出(办公室还在、压暗);**点质检台 → 验收队列**;**点观测室 → 完整可观测**;**晨报和深度回放**才是唯一两个全屏占据(因为那是"坐下来"的场景,不是一瞥)。**cozy 是索引,严肃是内容。**

### 2.2 状态色系统(一套色,处处用:小人光晕、小地图点、房间环境光)

把 `agent_node.status` 绑到一个色相,**同一色相在小人光晕、小地图点、房间环境光上冗余出现**——L0 还是 L2 都读得到。

| 状态 | 色 | 姿态/动效 | 灯 | 读作 |
|---|---|---|---|---|
| 空闲/待命 | 冷灰蓝 | 休息室里躺着、慢呼吸 | 暗 | 可用 |
| 干活(顺) | 暖青 `--work` | 敲键,稳 | 台灯稳亮 | 在码,正常 |
| 干活(打转) | 琥珀 `--warn` | 敲键但动画卡顿/循环、冒小问号 | 台灯闪 | 原地打转(§无进展) |
| **要你拍板** | **亮金,脉冲** | 站起、面向领导区、大问号 | 聚光脉冲 | **卡在你/经理这** |
| 受审中 | 青 | 走向/站在质检台 | 审计屏亮 | 正被验 |
| **审计否决** | **红,慢闪** | 低头、拿着分支纸 | 红洗 | **被打回,要管** |
| 已交付/合并 | 绿爆→淡出 | 走向发货口、货箱飞出 | 绿闪 | 完成,发了 |
| 冻结/急停 | 灰度、石质 | 半空冻住 | 无 | 我暂停了它 |

打转(琥珀)和失败(红)是 CEO 绝不能漏的两个,所以**只有它俩动**(闪/strobe)——动比静的颜色更抓眼。

### 2.3 预算 = 看得见的能量(不是角落一个数字)

预算是**建筑的电力**:运维·预算房一根**发光竖能量柱**,高度=剩余夜间预算,流下的光点=消耗速率;每个 agent 做一次决策冒一个火花(决策税你看得见)。**阈值是环境化的**:低于 30% 全办公室灯变冷变暗,低于 10% 屏幕边缘爬红/霜并触发叫醒。**你在读到任何数字之前,先感觉到公司在没电。** HUD 那根条是精确读数,房间是体感读数。

### 2.4 注意力信号三件套(最该突出的三个)

这三个是真正的干预触发器,给最强、最冗余的编码:
1. **要你拍板**:金脉冲 + 问号 + 小地图脉冲 + 屏幕边缘指向箭头 + `Tab` 队列首位 +(若预算危急)叫醒。**五条冗余通道,漏不掉。**
2. **打转**(§无进展):琥珀闪 + 敲键卡顿循环。故意比"要拍板"更轻——是软警告。
3. **审计否决**:红闪 + 拿分支纸 + 质检屏闪红 + 货箱**留在台上不发**("绝不自动改 main"被画成货箱**没走**)。

## 3. 相机与导航

- **连续缩放(核心)**:滚轮/捏合,**朝光标缩放**(光标下的东西不动);连续但 L0–L4 有 5 个**磁吸停靠点**,松手吸到最近的,你永远落在一个完整高度。
- **平移**:拖空地/WASD/边缘推;速度随缩放反比;**软边界**(超出橡皮筋回弹),非游戏玩家永远不会迷失在黑里。
- **跟随**:点小人 → `F` 锁定跟随,相机跟着它走 休息室→工位→质检→发货——**走的路就是状态机**。
- **房间聚焦**:双击房间标签/按房间数字键 → 框住该房间、其余压暗。
- **导航历史**:`[`/`]` 前后(连缩放级一起记)——你 L0→L4 扎进一个问题后能弹回原处(Factorio 2.0 最受欢迎的导航)。
- **跳到问题**:`Tab` = "飞到下一个需要我的"(按 要拍板→审计失败→打转→预算危急 优先级,自动缩到正确高度)。30 个 agent 时**你不找,按 Tab 它把问题端给你**。
- **小地图**:右下,每个 agent 一个状态色点,视口=可拖矩形,离屏的告警点也脉冲。

## 4. 手势 → 操作(每个手势 = 一次真后端写)

铁规则:每个手势 = 一次 IPC + 一次 Rust 操作(危险操作 Rust 验证后执行,UI 从不直接改 main/记忆/预算)。

| 手势 | 高度 | IPC | 后端效果 | 安全闸 |
|---|---|---|---|---|
| 拖员工到另一个经理房间 | L0/L1 | `reassign_node` | 重挂子树;在跑任务 SIGSTOP 后在新经理简报下续 | 在跑要确认 |
| 拖任务卡到休息室一个员工 | L1 | `dispatch` | 经理发 spawn,Rust 在新 worktree 起员工 | 决策税 + 工位容量 |
| 点房间 → 径向配置盘 | L1 | `configure_room` | 写该类节点的 `agent_role` 默认(模型/预算/扇出/权限/重启) | 角色版本+1,只影响未来 |
| 拉预算能量柱 | 任意 | `set_budget` | 写预算上限,实时更新消耗显示 | 不能低于已花;每任务保底 |
| 红色急停拉杆(全公司) | 任意 | `estop_all` | killpg 每个进程组(先 STOP 冻再 KILL,扫后代) | 急停永远允许 |
| 长按单个员工=石化 | L2 | `pause/estop_node` | SIGSTOP 那一个;再长按=杀 | 暂停可逆,杀要确认 |
| 点问号气泡 → 决策卡 | L2→L3 | `resolve_decision` | 解开阻塞、续上 | 选项即真决策 |
| 发货口盖章 接受/驳回/重做 | L4 | `accept_delivery` | 接受→合并列车;驳回→撤销;重做→回流 spawn | 仅在审计裁定已附后;**AI 永不合并** |
| 拖记忆书一条事实到 信任✔/退役✗ | L3 | `cite/flag_fact` | CEO 确认升 `权威`;退役标 `invalid_at`(不删) | **CEO 能授予 `权威`,AI 只能否决** |
| 拖 ＋可扩展 → 选房间类型 | L0 | `add_room` | 从模板实例化一类新节点 | — |
| 拖时间轴 | 任意 | `replay_seek` | 进只读回放(agent 重走录制路径) | 只读,拖回"现在"才动 |

**防误触**:破坏性写要么手势本身无歧义(急停拉杆物理独立且红),要么 1 步**在场内**确认(小人可见地"绷住"再被杀)。可逆写即时提交 + **撤销 toast**(5 秒"撤销")——因为后端已有 `restore_point`/revert,撤销很便宜,到处都该有。

**渐进放权**:新 CEO 从**只读**起步(手势可见但失效、光标显示锁),首次引导逐个解锁(先场内接受→派活→改派→预算/急停)。**空间 UI 永不变,能力逐步开。**

## 5. 下目标 · Brief Card(主操作,要做到最好)

**一张任务卡,不是聊天框。** 卡="我在写一个交付物",聊天="我得一轮轮指挥它"(后者是不信任、微管理的失败模式)。

```
┌─ 新任务 ──────────────────────────────┐
│ 目标(只此一项必填,大字输入框)         │
│ [ 给设置页加暗色模式,记住选择,跟现有 token 走 ]│
│                                        │
│ + 仓库   + 完成标准   + 护栏   + 预算   │  ← 可选 chip,想加才展开
│ (拖截图/Figma 链接/日志到这里)         │
│                              [ 交给经理 ▸ ]│
└────────────────────────────────────────┘
```
护栏 chip(如"别碰 auth/""不准加依赖""UI 改动要我看")是**真的**——编译成 worker `SpawnConfig` 的工具/路径禁用,不是建议。

**经理复述握手(成败关键):没看到经理复述理解之前,不花一分钱、不派一个员工。** 提交后经理跑一次便宜的、有界的范围评估,返回:

```
┌─ 经理这样理解 ─────────────────────────┐
│ 目标   给设置页加可记住的暗色开关        │
│ 计划   1.加暗色 token 2.开关组件 3.持久化│
│ 会动   settings/ theme/ store/          │
│ 不动   auth/ (按你的护栏)               │
│ 估计   1 个员工 · ~$1.80 · ~25 分        │
│ ❓ 两个不确定:                          │
│   跟随系统主题 还是 只手动? [跟随][手动][你定]│
│   没找到 token 体系,要新建吗? [是][否] │
│                  [改任务]  [看着对 → 开始]│
└─────────────────────────────────────────┘
```
- 澄清问题 **0~3 个、一点就答**;歧义小就不问(别制造摩擦);"你定"永远是第三选项(把子决策还给经理,记为委托决策)。
- **计划+路径+估价就是合同**,"看着对→开始"是授权花钱的那一点。框成"你听懂我没",不是"求你批准"。
- 若该经理 `require_plan=off`(已信任),范围预览仍以**可消除的 toast** 显示 ~6 秒("经理要开始 X — ¥1.80 — 按住可审")再自动开。**信任省掉一次点击,从不省掉可见性。**

## 6. 监督与陪伴:安静默认(95% 的时间,包括你睡着)

**办公室即余光。除非越过硬线,什么都不打扰你。** 一瞥要在 2 秒内回答"一切都好吗"。

- **三层注意力**:① 余光(不用读)=办公室整体氛围(忙/静/卡);② 一瞥可扫=姿态+一个状态小图标(复用 `poseMachine`);③ 前景(你主动拉/硬线触发)=展开看实时事件流/diff/经理理由。
- **状态条**(顶或底,一行真相):`🟢 3 在干 · 1 等你 · ¥4.20/¥20 · main:绿 · 下次合并 ~4 分`。`main:绿` 是全 app 最让人安心的字——它复述了最重要的不变量是安全的。
- **菜单栏呼吸灯(常驻陪伴)**:产品默认是关着的,全屏办公室是"凑近看"。常驻的是一个**菜单栏小灯**——绿脉冲=健康自治、琥珀=有人等你拍板、红抖=预算见底/main 回滚。点开=进 L0。**一个过夜自治公司应当默认安静、例外才吵**——这是别人都做反了的姿态(默认满屏遥测噪音)。
- **不在余光显示的**:逐 token 流、聊天日志、"经理在思考…"转圈剧场。叙述被降级,办公室只显示**真相**(在跑/卡住/合并),废话在下钻一层。

## 7. 干预:从轻到核(分级)

底层安全网:危险操作 Rust 拥有,**不存在"AI 无视我的停止"**。

| 手势 | 后端真做了什么 |
|---|---|
| 提点(给经理加备注) | 注入 `权威` 级备注进经理下次决策上下文;**不打断在跑员工**,落在下个决策点 |
| 改范围 | 改完成标准,经理下次重规划 |
| 改派(拖小人) | 真重挂组织树,worktree 跟着走 |
| 暂停 | **SIGSTOP 进程组**,冻在半截、可逆,预算停烧 |
| 杀任务 | killpg + 扫后代;worktree 留作取证、可重起 |
| **急停(全部)** | **先 STOP 冻全公司(防半截写完)、再 KILL、再扫后代;main 按定义不受影响** |

**急停设计(唯一绝不能失败或误导的控件)**:固定角落、像素红墙闸、永不滚走;**单击即冻**(SIGSTOP 在任何确认框之前落地——你一按公司就冻,框只问"恢复 还是 彻底杀");事后诚实横幅"公司已停,main 安全于 <sha>,3 个任务冻结 — 全恢复/全杀/逐个看"。**你能放心猛拍红闸,因为不可逆操作(合并/推)都被审计列车 Rust 闸住,员工永远不会正在 `git push` main——这份无所畏惧就是产品。**

## 8. 信任校准:让"信任=规划旋钮、不是破坏半径旋钮"一眼看懂

行业默认把"更自治"=" 更危险";我们必须把它拆开,而且用 UI 物理分隔。

```
┌─ 后端经理 · v4 ────────────────────────┐
│ 战绩(近 30 次交付)                     │
│   ✅干净合并 22  ↩回滚 1  🛑审计否决 4  ⤴升级你 3│
│ 漂移信号(本次运行)                     │
│   · 每任务花费 ↑40% vs 它自己基线  ⚠     │
│   · 同一失败测试重试 2 次          ⚠     │
│   · 测试改弱探针:0               ✓     │
│ ── 信任 = 规划自由度(不是危险) ───────│
│   权限      [ 问我 ●──────── 自动 ]     │  ← 旋钮在锁线上方
│   计划审批  [ 每个 ──●─ 大的 ─ 从不 ]   │
│   预算/次   [ ¥───●──────── ¥20 ]      │
│   扇出      [ 1 ●──── 4 个员工 ]        │
│ 🔒────────────────────────────────────  │  ← 锁线
│   永不可变:合并必须过审计 · 不能碰 main │  ← 铁律在锁线下方,灰、不可拖
│            · 不能写权威记忆 · 不能直接联网│
└─────────────────────────────────────────┘
```

**三个可读状态(全绑后端硬信号,不是凭感觉)**:
- **可信(绿、平静)**:高干净合并率、花费贴基线、无重复重试、0 改弱探针 → app 温和建议**升一档**("它干净合并了 22 次,让它自己开小任务?[试试]")。信任**往上挣**。
- **漂移(琥珀)**:漂移信号亮(花费爬升 vs 它自己基线、重复重试、否决连击)→ app **自动收一档并告诉你**("它烧得比平时快,我把每任务预算降了、大任务的计划审批开回来了。[看看]")。漂移→自动降**规划自由度**,诚实地告诉你。
- **失败(红、瘫)**:过夜回滚/碰预算底/重复升级循环 → 自动暂停等你,这是叫醒事件。

**最妙的一招**:**旋钮在锁线上方、铁律在锁线下方。** 非工程师一眼内化整个安全模型:**"更信任"最坏只是让它规划更大胆,永远不能让它搞坏 main。** 这是对"自治=风险"的解药。

**公司级自治拨盘**(命名预设):**监督**(每任务都要你点) · **过夜**(默认:预算内自动开、干净审计合并自动落、只有升级和碰预算线叫你) · **放手**(再加:攒晨报,只有红线叫你)。首次从监督起,随战绩 app 邀你往上爬。

## 11. 时间是一等控制(别人完全没有的)

过夜运行的主动词不是"读日志",是**"拖时间轴"**:
- **只读重演(便宜,先上)**:走账本到 T,**整座办公室重演到那一刻**(谁在干、main 什么、预算多少),像看比赛回放。每个历史运行都有"复盘"按钮。
- **确定性回放(调试)**:把 AI 输出/工具结果用录制桩替掉,重跑编排逻辑(§11 测试底座),"高级"开关后面,不是日常。
- **"如果当时…"分支(愿景部分,诚实分级)**:停在某个过去决策,**改一个输入**("预算上限若是 $8 会怎样")→ 重跑出一条**平行幽灵时间线**。v1 只做**账本能算出的**反事实(改预算/改审计结果),**生成式"如果"(真重跑经理)要花钱、不确定,单独 `重新模拟(实时·$)` 按钮、绝不默认**。

> 我们的双时间记忆(失效不删)+ 单提交点账本让"过去是真能重建的,不只是被记录的"——这是几乎没人有的架构属性,只用一个前向日志就浪费了。

## 12. 人事部:角色作者化(开源命脉)

- **房间布局**:花名册墙(经理/员工肖像卡)+ 档案柜(版本史)+ 图书架(可导入的社区模板)。
- **人设编辑卡**(字段 1:1 映 `agent_role`):角色/模型/简报(大编辑器,手艺所在)/能用工具/禁用/默认(预算·扇出·深度)/重启策略/记忆。**[在沙盒里试跑]**(拿录制桩对一个一次性 worktree 跑个小任务、先试后雇)。
- **版本化**(§14 硬要求):每次保存版本+1,在跑/暂停任务**钉住起始版本**;版本间(提示词)diff、可回滚。
- **可分享模板库**(开源钩子):人设导出成一个人类可读文件(markdown+config);内置起手人设(后端经理/测试员工/安全审计/前端员工)——**首次 CEO 从架上雇,第一天不写提示词**;"社区"页按**已发布战绩**(干净合并率/每任务花费/否决率)挑人,**按证据不按感觉**。导入≠信任(进库不自动雇)。
- **改进闭环**:每张卡显示自己战绩;"改进这个人设"按钮收集失败(被拒 diff/升级理由)起草修订版**待你审**(AI 提议、人/Rust 拍板),接受→新版本。

## 13. 命令栏 ⌘K(动词层,和办公室统一)

**两个输入面,整个模型挂在它俩上**:**办公室=在哪**(空间、安静、手势),**⌘K=干啥**(快、文字、键盘优先)。两者调**同一套 Rust 操作**——拖小人能做的,打字也能做。

⌘K 模糊匹配、按最近排序、按上下文过滤的动词:*新任务、提点、暂停、杀、急停、改派、雇人、设自治、开验收台、拖时间轴*。每条**内联显示快捷键**(边用边教)。它是精度层,也是无障碍/速度层。

## 14. 通知与叫醒模型

**只为(a)不理会就不可逆 或(b)越过安全/预算硬线 的事打扰睡着的人。**

| 层 | 例子 | 通道 | 时机 |
|---|---|---|---|
| **叫醒(立刻推)** | 预算碰硬底→自动暂停 · 审计过的合并回归 main → main 红 · 熔断触发急停 · 安全不变量违反 | macOS 推送 + 状态点变红,响 | 立刻,凌晨也叫 |
| **晨报(攒)** | 任务交付等验收 · 经理升级一个判断(非安全线) · 人设漂移已自动收紧 · 任务卡在冲突 | 攒进验收台+晨报,办公室显示问号/队列数 | 早上 8 点一瞥 |
| **静默(只在余光)** | 派活、干净合并、预算消耗、正常重试 | 只在办公室动效+时间线 | 从不通知 |

**默认几乎什么都不叫你**(整个卖点是"睡过去")。叫醒诚实、从锁屏可操作("Quiver 暂停了公司——预算碰底,main 安全,3 任务冻结",点→深链到对应控件)。**预算碰底叫醒本身是安全特性**(§5.8 终止保证可见化),措辞读作"我保护了你的预算"。**因为睡觉时 main 不可能不可逆受损(审计闸),晨报级永不自动升成叫醒级——你的睡眠由架构结构性保护。**

## 15. 首次引导(空办公室 → 第一次过夜运行)

**受众是非工程师 CEO。引导靠"做一件小而安全的事"教人机边界,不靠读。**

1. **空办公室(定向)**:开 app=暗的空办公室、灯灭、墙上红急停;中央一个脉冲 CTA "**点亮你的公司**"。命令栏/人事部/信任卡都存在但还没冒头(激进渐进披露)。
2. **设置坡道**(每步开下一步):① 连 git 仓库→一栋亮起;② **沙箱检查(硬闸)**——"AI 在你机器上跑代码前,先把它关起来",不可跳,这是 CEO 第一次学到"员工是被关着的",且卖成"为你";③ **从架上雇第一个经理**(后端经理 starter,不写提示词);④ **设过夜预算**(燃料表 + 急停闪一下教它存在,框成"你的");⑤ (可选)千问 key,可跳。
3. **带引导的第一个任务**:app 建议一个能验证的小目标,预填进 Brief Card → 你看到真的**复述握手**(我下目标、它复述) → 员工 spawn、干、提交,你**看办公室不看日志**(学陪伴) → 它走交付物到验收台,你看 diff+审计+说明,点**接受**→真 `git merge`,`main:绿` 跳一下(学"没我点头进不了 main,审计帮了我")。收尾提示:"这就是全部——下目标、瞥、批。要它不吵醒你自己干吗?"→ 引出自治拨盘(从监督起)。
4. **第一次过夜**:给真目标、设预算、去睡;一句话讲清叫醒模型。**高级面随用解锁**(用了第 2 个手势露 ⌘K;经理有战绩了才露信任旋钮;首次点"改进人设"才开编辑器)——**信任模型和引导模型是同一件事**:从不在你有证据设它之前把旋钮塞给你。

## 16. 美术指导

**定位**:一台戴着像素皮的平静操作台。**Stardew/Eastward 的温暖 + Linear/Raycast 的克制。** 凉得能整夜挂二号屏,清得 2 点一瞥就懂"3 在干、1 等我、预算 60%、没事着火"。

**先拍一块板**:仓库里两套打架的美术圣经——夜间工作室(原型,冷蓝+琥珀)vs 弓手公会奇幻(老 assets + 绿弓手 hero)。**全押夜间工作室;弓/箭只留在品牌层(logo/图标),不进办公室。** 否则每张生成图都往奇幻暖色跑、跟原型对打。

### 16.1 像素/等距风格系统
- **网格纪律**:2:1 等距、64×32 基块;**1 美术像素=2 屏幕像素**,绝不分数缩放;**全场一个像素密度**(16px 图标和 200px 服务器架共用同一像素大小)——这是"手工感 vs AI 糊"的分界;**整像素步进**,无 sub-pixel。
- **混合渲染(Eastward/Dave the Diver)**:**脆的低分像素 sprite/道具 叠在 略高分、有柔光的房间壳上**。**契约:sprite 像素纯净;光允许柔。**
- **三段令牌调色板**:**底色带**(夜间工作室冷暗,~16 阶)+ **角色强调带**(6 个冷偏配色,比原型降饱和~12%)+ **状态带**(§2.2 那套,sprite/光池/屏幕/预算柱/审计台同一套)。**冷底色,被珍贵的琥珀点亮**——这一个暖/冷对比扛 80% 情绪,琥珀绝不当壁纸。
- **光照=主信道+主情绪**:① 静态键/补光(右上键光,全场一致);② **每员工屏幕光(最强状态信号,0.8Hz 慢呼吸)**;③ **昼夜长弧——公司呼吸**(开跑黄昏暖、深夜窗最暗灯池最亮、临晨冷蓝从窗爬进=晨报将至、空闲灯落成余烬猫睡了——房间随公司休息);④ **预算=全局调光**(钱越少灯池越小越冷、琥珀褪向灰,到底=应急红边光)。
- **材质/边线(手工感的破绽)**:**选择性彩色描边,绝不纯黑**(向局部色相偏暖暗/冷暗,光打到的顶边不描);**克制抖动**只用两处(光池 2 阶渐变、地/木 ~10% 颗粒),**绝不随机抖动**(AI 糊签名);**手工稀疏 AA** 只在关键剪影几个像素;**材质靠阶梯不靠光泽**;**每个 sprite/道具一个柔椭圆接触影**(40% 黑、1px 左 2px 下),不然"贴纸悬浮"。

### 16.2 角色设计语言(靠剪影+配色+道具+待机区分角色,绝不用 emoji/浮动图标/标签)
共享底盘(24×38、3 块高、右上键光、同肤色),差异在 头/肩形 + 一个道具 + 配色带 + 待机。**32px 涂黑剪影测试:每个角色仍可辨。**

| 角色 | 剪影 | 配色 | 道具 | 待机 |
|---|---|---|---|---|
| **你/CEO** | 最高、最宽肩、披风长摆、无兜帽、微背光 | 唯一暖金 | 无(手背后) | **不坐工位**,站领导区或跟你光标 |
| **经理** | 兜帽、髋间夹着书、沉稳 | 暖琥珀(冷房里的暖) | **记忆书**(发光书脊,记账时变亮) | 慢翻页/托腮思考,坐主桌 |
| **员工** | 兜帽、耳机、前倾"在键盘前"、最小最忙 | 6 个冷强调之一 | 耳机+腰间任务牌 | 敲键 bob、偶尔伸懒腰/咖啡 |
| **审计(独立)** | 直立、抱臂、面罩/单片镜、夹板;站一旁不混 | **最冷最中性的青(制度感、不可腐蚀)** | 夹板+图章 | 哨兵般站质检台,来活转身面对,从不去休息室 |
| **图书管理员** | 佝偻、温和、抱纸条、圆剪影、老花镜 | 哑沙绿(背景人) | 纸条堆+提灯 | 沿书架慢移、归档、不急、夜里安静干 |

**状态表达(全角色一套词:姿态+光池+一个手绘像素小图标,绝不用 emoji)**:干活=敲键前倾+蓝慢脉冲;紧张(跑测试)=僵+汗珠+快 bob+橙;庆祝(合并)=举手+2 帧跳+手绘像素纸屑;失败=瘫+灰+灰烟;**要你拍板=直立看 CEO 区+琥珀脉冲+头顶问号点慢闪(最重要的一个图标,调成平静房里最亮的动)**;空闲=斜靠+像素 z。

### 16.3 房间身份与环境叙事(<1 秒读懂 + 住人感)
住人感 = **不对称 + 累积 + 一盏暖灯 + 一个"干过活的痕迹"**。休息室(最暖、沙发咖啡冒汽、**睡猫**、半读的书、两个杯子、略过盛的植物) · 工位区(冷蓝屏光、整齐桌网格、**每张桌随运行累积咖啡杯便利贴=工作日志**) · 领导区(暖、**记忆书在讲台,学得越多书脊越亮**) · 质检台(**最冷最素最制度、故意不装饰**——它的无菌就是"不可腐蚀的法庭") · 图书馆(尘暖中性、书里插着纸条=待审事实、**有些灰掉的书脊=失效记忆**) · 运维·预算(工业、保险柜+发光能量管=预算,先变暗) · 发货口(每次合并一个货箱飞出门、门口堆着今晚产出) · ＋可扩展(脚手架+蓝图地=邀你雇子团队)。**跨房间杂乱程度=今晚多累的可读时钟,晨报时清空。**

### 16.4 "高级感、不塑料"硬规则
**做**:一个像素密度铁律 · 锁定调色板量化 · 彩色选择性描边 · 手工 AA/抖动只在过渡 · 右上键光 · 接触影 · 暖/冷对比 · 留白(空=高级) · 状态=光+姿态+像素小图标。
**不做**:❌ emoji/浮动 Unicode 当场内 UI(**原型里 `⌨✓✕☕` 全换手绘像素图标——这是头号塑料破绽**) · ❌ 纯黑描边/全局 AA/模糊 · ❌ 随机噪声抖动 · ❌ 混像素大小 · ❌ sub-pixel/拖影/60fps 抖 · ❌ 饱和彩虹(强调要冷/哑,琥珀珍贵) · ❌ 像素层上玻璃拟态/投影(柔效只在光层和 HUD chrome) · ❌ 装饰审计台 · ❌ 纯装饰道具(每个道具都该编码状态或历史)。
**生成式工作流注意**:ComfyUI 生成只用于**房间壳和大道具**;**角色和任何 ≤24px 资产必须手工收尾**(t2i 缩下来密度不一、阶梯糊=塑料签名)。

## 17. 动效与 game-feel(像素低帧,绝不 60fps 塑料)

**帧预算:待机 2~4 帧循环,转场缓但脆,环境慢。静止是特性**——平静房+几个呼吸细节比满屏动更高级。
- **待机层(always-on 生命)**:敲键 bob、偶尔伸懒腰/喝咖啡;经理翻页托腮;猫呼吸+偶尔抖耳/换姿势;咖啡汽、服务器 LED 异相闪、浮尘;窗外慢视差星云+偶尔一颗流星(奖励守夜人)。
- **派活/走/庆祝**:经理冒决策火花→员工"收到"走廊路由→坐下、屏幕光柔脉冲亮;走=整像素 2 帧腿+方向翻+落脚小尘;合并=绿闪+2 帧跳+像素菱形纸屑+货箱飞出;失败=红闪、瘫、**比骄傲走更慢**地挪回休息室。
- **预算=能量(招牌系统级 juice)**:**整个房间的亮度就是预算表**——你不看条,你看建筑在变暗。HUD 条留作精确读数。
- **昼夜呼吸**:让 6 小时运行像一个"夜"而不是一个循环。挂二号屏的命门。
- **要你拍板的拉力**:有人需要你时,那个员工琥珀脉冲**微微加强且周围房间略暗**(柔聚光)——不弹窗,平静软件式地说"你被需要了"。
- **反塑料**:不常驻弹跳(只在状态时);不处处可爱过冲缓动;不粒子刷屏。**动效是句子不是烟花**——任一刻大部分屏幕是静的,动起来就该有意义(派活/合并/决策),三样同时动=真发生了三件事。

## 18. 设计系统与令牌(两个声音,干净分开)

- **像素=世界;Inter/SF=操作员 HUD。** 这个分离本身是高级信号(游戏 cozy、控件锋利)。
- **颜色令牌**:底色/角色强调/状态 三带,单一真源(`frontend/src/office/palette.ts`),`--pixelize` 全量化到它。组件里用 `var(--qv-*)`,禁硬编码色值(符合 react 规约)。
- **排版**:UI/chrome=**Inter/SF Pro**(中文配 PingFang SC,正字距 0.1~0.3px,Raycast 暗底通透感);数字/mono(预算/计时/任务ID/审计日志)=**SF Mono/JetBrains Mono**(等宽数字防抖);像素字面**只**用于门头 QUIVER 招牌和启动页,绝不进正文 UI。
- **HUD chrome(叠层界面外壳)**:深色玻璃 + 等宽数字 + 像素滚动条;柔效(模糊/投影)只在 chrome 层,不碰像素层。
- **组件**:状态条、命令栏、Brief Card、Trust Card、晨报、审阅卡、因果树节点、时间轴、抽屉、菜单栏呼吸灯——每个是一段数据库的"读侧",不是装饰。

## 19. 无障碍(承重在"批准 main"这条法律级路径)

整座移动的 30-sprite 办公室对读屏是敌对的,**别假装那是无障碍面**。
- **并行语义树**(AccessKit 支撑、按组织层级而非像素结构):读屏走这棵树。
  ```
  公司(预算剩 62%,$0.40/分 在烧)
  ├ 经理 Ada — 3 员工,1 等决策
  │ ├ 员工7 — 要决策:"auth.rs 冲突,重试还是升级?" [接受][驳回][重做]
  │ └ 员工4 — 在跑,8 分没提交(打转)
  └ 合并列车 — 1 个等你批:分支 fix-login [+40 −12] [接受][驳回][重做]
  ```
- **注意力队列=ARIA live region**:状态一翻就**朗读**("员工7 需要一个决策"),对齐金色箭头视觉。
- **接受/驳回/重做是真可聚焦按钮**(读出审计裁定+diff量级+经理说明)——验收队列零空间交互即可操作。**这是"main 永不坏+人来裁定"必须人人可达的那一面。**
- **L4 diff 渲染成可读文本**(逐 hunk 可导航),不是 diff 的图。
- **命令栏=键盘/读屏主入口**(纯文本进出,无需空间推理)。
- **降动效模式**:闪/strobe 降成稳定图标+边缘箭头(位置非颜色);**绝不只靠颜色**(每个状态色配一个不同形状的像素小图标);**可选音频提示**绑三个关键信号(要拍板软铃/失败低音/预算低嗡)。

## 20. 多仓库 / 多项目 UI(§17)

v1 支持一个公司管 N 个**独立**仓库:顶部仓库 tab 条,每个仓库是**floorplan 的一翼**;筛选器里仓库是顶层维度("跨 3 仓库的所有打转 agent"一键)。跨仓库原子改动做成**已知限制**(明说 punt),schema 现在为它留好。

## 21. 要避开的花架子(智能体点名,看着炫实则有害)
❌ VR/3D 办公室(杀掉一瞥可读、进不了菜单栏、8 点咖啡时没用) · ❌ 把聊天框当主控(把可审计的空间结构藏回一条易失文本流,正是竞品困在的贫瘠隐喻) · ❌ 无限免费"如果"(demo 谎言;真 what-if 要么账本派生要么 `$` 按钮) · ❌ 满屏实时遥治(calm 反模式) · ❌ 会自己重排布局的 UI(用户靠空间记忆导航,**改强调/深度/色温,不改地形**) · ❌ 小人演戏成了唯一真相来源(每个动画必须忠实映射一行数据库)。

## 22. 分阶段落地(哪块 UI 何时上,对齐架构 §23)

| 阶段 | UI 上什么 |
|---|---|
| **P0–P1** 跟后端地基走 | L0–L2 只读办公室 + 状态色 + 预算能量 + 小地图 + 菜单栏呼吸灯 + 状态条(纯读 `agent_node`) |
| 同期 | **注意力队列 + `Tab` 跳 + 边缘箭头 + 命令栏 + 读屏语义树**(让它从玩具变控制台的核心) |
| **P2 记忆上** | 缩放到 L3/L4(记忆书+决策卡+桌上 diff)+ 决策快照(需 `decision_log`)+ 因果树 |
| **P3 安全上** | 验收/审阅卡(需独立审计)+ Trust Card(旋钮在上铁律在下)+ 急停真杀 + 漂移信号 |
| **P3–P4** | 晨报 + 通知/叫醒三层 + 自治拨盘 + 可写手势(渐进解锁:场内接受→派活→改派→预算→急停→记忆信任) |
| **P4–P5** | 时间轴只读回放 + 人事部(人设作者化/版本/模板库)+ 多仓库翼 + what-if(账本派生先,实时重模拟后) |
| 全程 | 美术(§16)从第一块"key art"立标杆:深夜主楼层 + 经理抱记忆书待机,手工收尾证明密度/AA/描边规则;**去 emoji 换手绘像素图标是最早、最高杠杆的一步** |

**最该先做对的**:§2.4 三个信号(要拍板/打转/审计失败)× `Tab` 跳一键到位。**一个睡眠不足的非工程师 8 点醒来,按三下 `Tab`,把公司卡住的每件事 接受/驳回/重做,全程不用看说明书**——空间 UI 就配当控制台,而不是屏保。
