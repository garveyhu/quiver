Quiver · 像素主题方向

彻底重来。像素风锁定(低帧动画是像素风的天生优势,正好绕开"做不出流畅高帧"的限制)。下面只换世界观/隐喻,核心都是「过夜监工一群小工替你干活」+ 一套角色 5 状态。挑一个主题。

不变的内核

一个任务=一个后台 AI agent=一个像素小工。5 状态:干活 · 卡住(等你/限流/预算到顶) · 紧张(跑测试) · 庆祝(验证通过已合并) · 崩了(失败)。要 cozy、夜里看着安心、信息一眼可读。每个主题下面标了这 5 态在该世界里长啥样。需要的资产都一样:主场景 / 角色+状态 / 工位道具 / 炉火等特效 / UI / 品牌——全像素,走 skill 的 t2i→pixelize→matte 管线。
